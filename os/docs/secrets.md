# Secrets and credentials

> **Golden rule:** this project lives in a **public** repository (`.eiskaffee`). No secret, token or private key may be versioned here.

## Sensitive artifacts (do NOT version)

These exist on the old machine and **must be transferred manually** (over a secure channel), never through the public repository:

- SSH keys (`~/.ssh/`) — generate new ones or copy them securely.
- `~/SamsungCertificate/` (Samsung/Tizen signing certificates).
- `~/.env` (project variables), if you use one.
- Corporate certificates — see [`certificates-macos.md`](./certificates-macos.md).
- `~/.zshrc` env vars exported directly as literals — e.g. `FANTASCOPE_TOKEN` (Azure AD JWT generated by internal CLIs such as `uolplay-cli`) or any other `export X_TOKEN="..."` tied to your corporate identity. Never copy the literal value into a script/doc; regenerate it on the new machine with the tool that issued it. See [`zsh-terminal.md`](./zsh-terminal.md) for which parts of `~/.zshrc` ARE safe to port.

Any project- or service-specific tokens are read directly by the tools that need them (e.g. a plugin prompting for its API key on first use), so there is nothing to store in this repository.
